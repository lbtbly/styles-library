Built for the part nobody demos

Getting a model to answer once is easy. Keeping it answering under load, across regions, at a cost you can defend — that is the work.

Compile once

Upload weights in any common format. Meridian quantises, compiles and caches a per-architecture artefact so every region boots from the same binary.

Scale to zero

Idle deployments cost nothing. Traffic wakes capacity in the nearest region and drains it again when the burst passes.

Per-token accounting

Every request carries region, model version and cost. Export it to your warehouse or read it from the dashboard.

Three lines to production

The SDK is deliberately small. If you can call an HTTP endpoint, you can deploy on Meridian.

deploy.py
from meridian import Model

model = Model.compile("./weights/atlas-7b", quantize="int8")
model.deploy(regions=["fra", "iad", "sin"], scale_to_zero=True)
